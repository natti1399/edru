## Hva er EDRU?

EDRU er en gratis app laget for norske studenter som vil prøve en **hvit måned**, kutte ned på alkohol, eller bare ha bedre oversikt over edru-dagene sine.

Ingen dømming. Ingen reklame. Bare et enkelt verktøy som heier på deg.

## Funksjoner

- **Streak-teller** — Se hvor mange dager du har vært edru, med en visuell fremgangsring
- **Festlogging** — Logg edru fester og se at du mestrer sosiale situasjoner uten alkohol
- **Statistikk** — Beste streak, totalt edru dager, månedlig oversikt og streak-historikk
- **Milepæler** — Feir 1 dag, 1 uke, 1 måned og mer med personlige gratulasjonsmeldinger
- **Ny start uten skam** — Glapp? Ingen stress. Start på nytt uten å miste total fremgang
- **Hvis-da-planer** — Lag en plan for hva du sier når noen tilbyr deg alkohol
- **Varslinger** — Velg mellom stille, daglig sjekk eller helgestøtte (fredag + lørdag)
- **Personvern først** — All data lagres lokalt på din telefon. Ingen konto. Ingen sky.

## Personvern

EDRU tar personvern på alvor:

- All data lagres **lokalt på enheten din** med kryptering (AES-256)
- Vi samler **ingen** personlig informasjon
- Ingen konto kreves
- Ingen sporing, ingen analyse, ingen reklame
- Du kan slette all data når som helst med ett trykk
